## 一、这步到底是咋回事（大白话版）

P0 是「先把公司里所有单据长什么样定死」，像先把表格印好，但还没人上班。
**P1 就是让公司第一天开张**：装上人事档案（数据库）、装个调度室（引擎）、装个前台窗口（网页）、招两个能干活的人（总经理 + 一个执行席位），然后跑一笔真实业务看看会不会卡住。

打个比方：

| 公司里的东西 | 代码里叫啥 | 干什么用 |
|---|---|---|
| 前台收件窗口 | Web Board / 统一 API | 你在网页上写一句话交需求 |
| 调度室 | `engine.js` 的事件泵 | 谁该干活了就打电话叫谁，不用人催 |
| 人事档案柜 | SQLite 数据库 | 每张卡、每次叫醒、每笔审计都记下来，关机也不丢 |
| 打电话叫人 | `adapter.execute()` | 只用「打电话」这个统一动作，不管对面是哪家 AI 产品 |
| 交作业回执 | `CompletionReport` | 干完必须交一张格式固定的回执，格式不对就打回重做 |
| 总经理签字 | CEO review | 回执合格才签字，签完才算 done |
| 下班简报 | 固定模板简报 | 今天办了几件、卡了几件、叫醒了几次，一条消息说清 |

**最要紧的一条**：整个过程是**一条命令自动跑到底**的。你提交需求后，调度室自己把后面的活一件件领出来办完——这是 G-P1 阶段门禁里最硬的一条。

---

## 二、为什么要做这步

设计文档（任务书 v1.0）写得再多，只要没跑通过一笔真实业务，就不知道字段定得对不对、状态会不会跳错、会不会重复建卡、会不会无限空转烧额度。P1 就是**用最小代价把整条链路捅一遍**，把藏着的坑在只有 2 个席位时先踩出来，别等接了 5 个真实 agent 再爆。

事实证明值得：**第一次跑测试就抓出一个一直藏着的底层错误**（建表语句里给 `rowid` 建索引，SQLite 不允许，数据库根本打不开），这个坑 P0 的 44 个测试碰不到，只有真正开库才暴露。

## 三、打算怎么改 / 我具体改了什么

### 3.1 新增文件

| 文件 | 作用 |
|---|---|
| `src/core.js` | 17 张表、状态机 `transition()`、事件表与去重、补偿扫描 |
| `src/engine.js` | 路由 → 建卡 → 事件泵 → Run Policy → adapter → 报告校验 → 验收 → 简报 |
| `src/adapters.js` | `process` / `cli-acp` / `mock` 三型插件，统一 `execute(ctx)` |
| `src/server.js` | 统一 API（REST + SSE）+ 内置网页服务 |
| `src/web/board.html` | Web Board 最小页：提需求、Tasks、席位、Approvals、Inbox、Runs、Audit、协作空间、变更请求 |
| `scripts/fake-agent.js` | 本地假 agent，不联网、不烧额度，只用来演示和跑测试 |
| `tests/p1.test.js` | 19 条 P1 验收测试 |

### 3.2 改动的既有文件

| 文件 | 改了什么 |
|---|---|
| `package.json` | 加 `start` / `test:p1` 脚本；`engines` 从 `>=20` 提到 `>=22`（内置 SQLite 需要 22） |
| `src/core.js` | `threads` 表加 `requestId` 幂等列 + 旧库自动补列迁移 |
| `src/engine.js` | 修 4 处（见 3.3）；加协作空间读写与消息发送 |
| `src/server.js` | 加协作空间读 / 发消息端点、`/api/approvals` 查询；审批单不存在时如实返回 404 而不是假装成功 |

### 3.3 顺手修掉的 4 个坑

| 坑 | 不修会怎样 | 怎么修的 |
|---|---|---|
| 建表语句给 `rowid` 建索引 | **数据库根本打不开**，P1 全线崩 | 索引只建在 `processed` 上 |
| `direct` 直投总经理时，抄送名单和交付对象写成同一个人 | 协议校验直接拒收，直投 CEO 用不了 | 抄送名单自动剔掉交付对象本身 |
| 总经理验收打回后没有次数闸 | 反复打回、反复重跑，**无限空转烧额度** | 只自动重跑一次，第二次留痕等人审；验收请求按 `runId` 去重 |
| 协作空间重复提交会重复建空间 | 幂等口径跟任务卡不一致 | 空间也带 `requestId`，并给旧库自动补列 |

## 六、怎么自己跑起来看

```bash
cd D:\开源\AICompany
npm start
# 浏览器打开 http://127.0.0.1:3100
```

不配任何环境变量也能跑：服务会自动用本地假 agent 演示，不联网、不烧额度。想接自己的 AI，把 `AICOMPANY_CEO_CMD` / `AICOMPANY_WORKER_CMD` 指到你的 CLI 命令，再照 `config/company.example.yaml` 写一份 `config/company.yaml` 即可。真实配置与 `.env` 已被 `.gitignore` 排除，不会进仓库。

停止服务：在运行 `npm start` 的终端按 `Ctrl + C`。
