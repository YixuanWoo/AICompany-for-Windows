# 任务与项目解耦 · CEO 可以只回话不派卡

> 2026-11-16 晚补丁。回答董事会两个问题：
> ① 不属于任何项目的「一次性任务」能不能跑？② 让 CEO 只出主意、不派活，会不会变成「问句你好也派一张卡给豆包」？

## 一、结论先说

| 问的 | 答案 | 状态 |
|---|---|---|
| 任务能不能不进项目 | **能**，`project` 为空就是一次性任务，产物留在公司工作目录，不写任何项目文件夹 | 原本就支持 |
| 一次性任务会不会被硬塞进项目 | 不会。执行席位拿到的原话是「本卡没有项目归属，不要往任何项目文件夹里写」 | 原本就支持 |
| CEO 能不能只看项目和记忆、只给建议不派活 | **现在能了** | 本轮补的 |
| 问一句「你好」会不会派一张卡给豆包 | **不会了**（以前会，而且有两种蠢法，见下） | 本轮修 |

## 二、以前有多蠢（真实现状，不是假设）

CEO 的输出处理里有一句 `const requested = (explicitTasks ?? [result])`——**没写 `tasks` 就把整个结果当成一张卡**。
于是「你好」会变成：一张标题「你好」的卡，派给执行岗豆包，豆包真的去写一段「你好的回复」，
走完验收、落盘、配额，全程烧的是真额度。

另一条路也不好：如果 CEO 乖乖写了 `tasks: []` 又没有排班建议，引擎会抛
「CEO 既没派卡、也没提排班，这一轮等于没产出」——这轮判失败 → 重试两次 → 卡住 + 升级救火。
**一句话的寒暄，换来两次失败重试。**

## 三、这次怎么改的

### 1. 判「这是不是一张卡」

新增 `looksLikeTaskCard()`：必须带 `title` / `instructions` / `assignee` / `acceptance` 之一才算卡。
只写了 `summary` 或建议的对象，是**回话**，不是活。

- CEO 没写 `tasks` + 只写 summary → 不建卡
- CEO 写 `tasks: []` + 写 summary → 不建卡
- 两个都没有、summary 也空 → **仍然报错**（不能把空白当完成）

### 2. 只回话的收尾：`closeAsReport`

父卡直接 `in_review → done`，答复原样交回董事会：

- 审计记一条 `ceo_report`（原文可追，最多 2000 字）
- 收件箱发一条 `scene: "answer"`（看板「简报」区显示正文；Windows 弹桌面气泡）
- 不建子卡、不进项目、不再唤醒第二次

### 3. 契约没破

P0 冻结的是「CEO 输出只有四类出口」，这条没动。所以**没有新增第五类**：
「只回话」用 `task-create + tasks: [] + summary` 表达，跟「只排班不派卡」是同一条路。

模型偶尔会自己写 `type: "report"` —— 引擎做**别名归一**（report / answer / reply → task-create + 空 tasks），
不判它非法，也不给它开新出口。

### 4. CEO 现在真能看到项目现状

以前给 CEO 的只有项目 id、名字、落盘路径——它只能泛泛而谈。
现在每个项目带**最近 3 条记忆**（日期 / 标题 / 摘要 / 第一条教训），压缩成一句话，避免每次唤醒都塞全文。

即：问「现在有什么该做的」，它是看着 `yitai` 上周体检发现了什么、`benny` 术语表缺什么在回答，不是靠猜。

### 5. 一次性任务的项目口径修正

提示词原来有一句「绝不为了先跑起来就把 project 留空」——这会让 CEO 连一次性小活也硬归项目。
改成两句，把边界划清：

- 真的一次性活（干完就散）**就该留空**，产物留公司工作目录，这是正常的；
- 本来属于某个项目的活**别偷懒留空**，否则产物 / 经验 / 交付全落不到项目里。

## 四、怎么用

| 你想干的事 | 怎么下单 | 会发生什么 |
|---|---|---|
| 翻译正文 / 干一件有产物的事 | 看板 → 高级选项：`direct` + 交付给执行岗 + 项目 `benny` | 跳过 CEO，机器验收，产物落 `04-译稿` |
| 跟 CEO 聊两句、问问现状 | 看板默认 `delegate`，项目留空 | 不建卡，答复进收件箱 + 弹气泡，父卡结案 |
| 让 CEO 出主意（看各项目有没有该做的事） | `delegate`，项目留空，话写清楚 | 它读项目记忆后回话；真有活了才拆卡 |
| 一次性小事（算个数、查个东西） | `direct` 点名，项目留空 | 产物留公司工作目录，不进任何项目 |
