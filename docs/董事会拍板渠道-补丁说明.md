# 补丁：董事会拍板渠道（“待我拍板”点不进去）

## 问题

看板左上角统计砖显示「待我拍板 1」，但找不到能拍板的地方。查下来是两层问题：

1. **审批单渲染成了空壳**：接口 `/api/approvals` 返回的申请内容字段叫 `requestJson`（字符串），界面却按 `a.request`（对象）读。结果审批卡只剩一行“AP-120b9808”加三个按钮，项目 id、落盘位置、验收条件全是空白——看起来就像没有内容可审，自然“拍不到”。
2. **名字骗人 + 没有提醒**：标签页叫「席位与审批」，点进去只有席位和配额，压根没有审批；审批卡藏在「任务与汇报」最底下，而且没有任何提醒。

## 改了什么（纯前端，不改服务端、不重启、不打断在跑的任务）

| 改动 | 效果 |
|---|---|
| 前端把 `requestJson` 解析成 `request` | 审批卡显示完整内容：项目 id / 落盘位置 / 为什么建 / 验收条件 / 固定规矩 |
| 页面顶部黄色提示条 | 有任何待审批/待决策，任何标签页都能看到「N 项审批等你拍板」，点「去拍板 →」直接滚到审批卡并闪边框 |
| 统计砖可点 | 「待我拍板」「挂起待决策」有数字时变黄、可点击，点了跳到对应区域 |
| 标签角标 | 「任务与汇报 · 1 待办」 |
| 浏览器标签标题 | 变成「（1 项待你拍板）AICompany · Web Board」，切到别的网页也看得见 |
| 标签改名 | 「席位与审批」→「席位与配额」（里面本来就没有审批，名字要如实） |

## 验证

用无头浏览器导出渲染后的真实 DOM 核对：

- 标签角标 = `任务与汇报 · 1 待办`
- 页面标题 = `（1 项待你拍板）AICompany · Web Board`
- 审批卡含「新建项目申请：译台」「项目 id：yitai」「落盘位置：D:\开源\YiTai」「验收条件 4 条」「固定规矩」，含「通过并创建」「拒绝」按钮和意见输入框
- 涉及看板的 80 个测试全过；页面脚本语法检查通过

## 边界

- 看板不开着就收不到提醒。要在关掉网页时也提醒，需要一个常驻的桌面通知脚本——没做，需要就说一声。
- 审批通过的“译台”项目只影响**之后**的派单：已经拆出来的 4 张卡是「一次性任务」，不会追溯挂到项目上。
