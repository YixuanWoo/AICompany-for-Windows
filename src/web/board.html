给总经理下指令

你说一句话，总经理自己判断归属（新项目 / 老项目 / 一次性任务），带团队拆活、执行、验收。提交后手离开键鼠，几秒后它自己开工。

高级选项（交互模式 / 难度 / 项目 / 交付给）—— 一般不填，交给总经理判断

任务卡 · Tasks

每条任务右边「看结果」= 总经理交回来的汇报与产物。点开就能读它说了什么。

收件箱 · Inbox

最近唤醒 · Runs

运行与审计 · Activity

选一张卡，把它的状态流转 / Run / 变更 / 决策 / 审批 / 版本 / 现场快照按时间串起来看。

挂起待决策 · Decisions（§6D）

卡在 awaiting_decision 的任务：挂起期间不烧额度、不被补偿扫描重跑。四种出口任选其一。

审批 · Approvals

三道常规门禁（strategy / hiring_budget / review_reject）＋两类按需人审（replan / 循环改版）。 看完直接点：通过 / 要求重写 / 驳回。顶部黄条出现时，点它就能跳到这里。

新建项目

正常不用你填：总经理认为该单开项目时，会自己递一张「新建项目申请」到「席位与审批」页， 项目 id、名称、落盘位置、验收条件、固定规矩都由它填好，你只选通过 / 拒绝，有意见写在申请单下面。 下面这张表只是兜底（比如你想先建好项目再下单）。填了落盘目录 = 授权引擎把验收通过的产物复制过去。

手工兜底：我指定项目信息（一般用不到）

项目 · Projects（P7）

项目是公司里的记忆单元，也是交付物的落点。规范与经验存在公司，产物验收通过后复制到项目自己的文件夹。 下单时可以不选项目 —— 总经理会自己判断归属，或复用这里的老项目。

席位 · Agents

配额 · Quotas

按周期记账：用到 80% 预警一次，到 100% 停派新活；换人 or 重置可恢复。

协作空间 · WorkThread

cowork / meeting 的消息只留痕，不建卡。会议三档：readonly 零唤醒 / rollCall 点 2 位 / full 全员+汇总（要二次确认）。

中途变更 · ChangeRequest（§6D 最小档）

对一张未完成的任务卡「刹车」：唤醒总经理→ 派生新卡 → 原卡 cancelled，历史仍可查。

清理扫描 · Cleanup（只出报告）

宁可不删，也不误删：只扫描、只写报告，deletedCount 恒为 0。 Desktop / Downloads / Documents / AppData / 系统盘 / .ssh 一律拒绝，且一个文件都不写。

试运行观测 · Observe（P5）

五项指标 + 四项结论 + 脏状态，全部从控制面自己的记录算出来。注意：压缩跑不能代替真实 72 小时， 门禁结论只认 npm run soak:real 出的报告。
